## 문제 설명

삼각형의 세 변의 길이가 주어집니다. 이 삼각형이 직각삼각형인지 판별하는 프로그램을 작성해 주세요.


## 입력

첫째 줄에 삼각형의 세 변의 길이 A, B, C가 공백으로 구분되어 주어집니다. (1 ≤ A, B, C ≤ 1,000)


## 출력

해당 삼각형이 직각삼각형이면 YES, 그렇지 않으면 NO를 출력합니다.



### 예제 1

**입력**

```text
3 4 5
```

**출력**

```text
YES
```


### 예제 2

**입력**

```text
5 6 7
```

**출력**

```text
NO
```
