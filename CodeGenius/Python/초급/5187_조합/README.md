## 문제 설명

정수 A와 B가 입력될 때 A개의 원소에서 B개의 원소를 뽑는 조합에 대한 총 경우의 수를 출력하는 프로그램을 작성하세요.


## 입력

첫 번째 줄에 정수 A와 B가 공백을 기준으로 입력됩니다. (1 ≤ B ≤ A ≤ 30)


## 출력

A개의 원소에서 B개의 원소를 뽑는 조합에 대한 총 경우의 수를 출력합니다.



### 예제 1

**입력**

```text
10 5
```

**출력**

```text
252
```


### 예제 2

**입력**

```text
7 2
```

**출력**

```text
21
```
